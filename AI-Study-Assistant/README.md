# AI-Powered Smart Study Assistant
1. Install Node.js LTS.
2. Extract this ZIP.
3. Open VS Code in the extracted folder.
4. Terminal 1: `cd server` then `npm install`, copy `.env.example` to `.env`, put your Gemini API key, then `npm start`.
5. Terminal 2: `cd client` then `npm install` then `npm run dev`.
6. Open the Vite URL shown in terminal (usually http://localhost:5173).
7. Upload any text-based `.pptx` and click Analyze with AI.
